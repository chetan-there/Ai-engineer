1. What is a Python Installation?
When you install Python:
Python 3.11
Python 3.12
Python 3.14

Example:
C:\Program Files\Python311\python.exe
or
C:\Users\cheta\AppData\Roaming\uv\python\cpython-3.12.13\python.exe
These are completely separate Python installations.
________________________________________
2. What is a Virtual Environment (venv)?
A virtual environment is an isolated copy of Python.
Example:
System Python
│
├── Project-A
│   └── .venv
│
├── Project-B
│   └── .venv
│
└── Project-C
    └── .venv
Each project gets its own packages.
________________________________________
Without venv
You install:
pip install tensorflow
globally.
Now every project uses that TensorFlow version.
Problems:
Project A needs TensorFlow 2.15
Project B needs TensorFlow 2.21
Conflict.
________________________________________
With venv
Project-A
└── .venv
    └── TensorFlow 2.15

Project-B
└── .venv
    └── TensorFlow 2.21
No conflict.
________________________________________

4. What is a Kernel?
Kernel ≠ venv
People confuse these.
________________________________________
venv
Stores:
Python
Packages
Libraries
Example:
.venv
├── pandas
├── numpy
├── tensorflow
└── nltk
________________________________________
Kernel
Runs notebook code.
Notebook
    ↓
Kernel
    ↓
Python Environment
________________________________________
Example:
print("Hello")
The kernel executes it.
________________________________________
5. Relationship
Notebook
   ↓
Kernel
   ↓
venv
   ↓
Packages
________________________________________
6. What is uv?
Traditional:
python -m venv .venv
pip install pandas
Modern:
uv venv
uv add pandas
uv is simply:
Faster pip
Faster venv
Better dependency manager
That's all.
